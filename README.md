#  Heart Disease Prediction Web App

A Machine Learning based web application that predicts the risk of heart disease using medical parameters.



## 🚀 Live Demo

🔗 Live App: (https://heart-disease-prediction-web-app-1.onrender.com)



## 📌 Project Overview

This project uses Machine Learning to predict whether a person is at risk of heart disease based on clinical parameters.

The system:

- Trains a Logistic Regression model
- Saves the model using joblib
- Deploys a Flask web application
- Hosted on Render cloud platform



## 🧠 Machine Learning Model

- Algorithm: Logistic Regression
- Dataset: UCI Heart Disease Dataset
- Features: 13 medical attributes
- Accuracy: ~85%

### Features Used:

- Age
- Sex
- Chest Pain Type
- Resting Blood Pressure
- Cholesterol
- Fasting Blood Sugar
- Rest ECG
- Maximum Heart Rate
- Exercise Induced Angina
- ST Depression (Oldpeak)
- Slope
- Major Vessels (CA)
- Thalassemia
